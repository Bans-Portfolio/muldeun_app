# 006. 다이어리 카드 BOTTOM OVERFLOWED

## 환경
- Flutter 3.44.0 / Chrome (web)
- 발생 위치: 다이어리 화면 사진 카드

## 문제 상황
다이어리 화면의 사진 카드 하단에 노란-검정 줄무늬 경고(`BOTTOM OVERFLOWED BY ... PIXELS`)가 표시됐다. 사진·날짜·메모가 한 카드 안에 다 들어가지 못하는 상태였다.

## 원인
카드에 할당된 높이가 콘텐츠(사진 + 날짜 + 메모)를 세로로 쌓기에 부족했다. Flutter는 자식 위젯이 부모 영역을 넘으면 오버플로우 경고를 표시한다.

## 해결 과정
세로로 쌓는 레이아웃 대신, 사진 위에 정보를 겹쳐 올리는 방식으로 재설계했다.
1. 사진을 카드 전체에 채우고,
2. 사진 위에 **반투명 그라데이션 오버레이**를 깔아 그 위에 날짜를 표시,
3. 색상 표시 점에는 흰 테두리를 더해 어떤 사진 위에서도 가독성을 확보.

## 결과 / 배운 점
- 오버플로우 경고 해소.
- 정보를 사진 위에 띄우면서 디자인 완성도도 함께 개선됨.
- 고정 높이 컨테이너에 콘텐츠를 욱여넣기보다, **레이아웃 구조 자체를 바꾸는 편이 근본적인 해결**이 될 수 있음을 학습.
